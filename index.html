1. Introduction

FlexCover is a cover-song generation model that conditions a pretrained text-to-song foundation model on a symbolic lead sheet. The user can freely combine reference music, lyrics, and style to produce a new cover. We support two task families:

  • Full-Song Cover. Re-render an entire song under a new style. The reference can be combined with either the original lyrics or with new lyrics provided by the user.
  • Partial-Reference Song Cover. Only a portion of the reference is observed; the rest is freely generated. Three configurations: continuation (only the song's beginning, up to the first chorus, is visible), outpainting (only the first chorus is visible), inpainting (everything except the first chorus is visible).
